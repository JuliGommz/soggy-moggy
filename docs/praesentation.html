05 — Architektur

Skript-Struktur

input.js
→ keys{}
Tastatur + Maus-Eingaben
game-state.js
→ GameState, GamePhase
Zustand + State Machine
background.js
→ updateBackground, renderBackground
5-Layer-Parallax, Tag/Nacht
←
main.js
Canvas · Loop · HUD
update() + render()
Orchestrator
→
player.js
→ player, updatePlayer, renderPlayer
Physik, Sprites, Animation
platforms.js
→ updatePlatforms, checkPlatformCollisions
Generierung, AABB-Kollision
water.js
→ water, updateWater, renderWater
Flut, Leben, Damage-Flash
index.html lädt alle 6 Module als <script>-Tags vor main.js. Kein Bundler. Globaler Scope als bewusste Entscheidung für Unterricht. Call-Order ist load-bearing — updatePlayer → updatePlatforms → checkPlatformCollisions → updateCamera.
