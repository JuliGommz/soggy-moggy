# PixelArt

Alle Sprite- und Hintergrund-Assets des Spiels **Soggy Moggy / Gato Sin Botas**.
Erstellt mit **Pixelorama** (`.pxo`-Quelldateien) und Adobe Illustrator (`.ai`).

## Ordnerstruktur

| Ordner | Inhalt |
|---|---|
| `backgrounds/` | Parallax-Hintergründe für Level 1 (Stadt), Level 2 (Aufzugschacht), Level 3 (Leuchtturm/See) |
| `characters/` | Figuren-Sprites (`cat/` Spieler, `wasp/` Gegner) |
| `collectibles/` | Spawnbare In-Game-Pickups (Luftballon-Extraleben) |
| `fonts/` | Aktive Bitmap-Schriftarten (PNG) und Illustrator-Quelldateien |
| `platforms/` | Plattform-Sprites für alle drei Level |
| `thought_bubbles/` | Sprachblasen und Dialogue-Bubble-Assets |
| `ui/` | UI-Assets (`hud/` HUD-Herzen; `screens/` reserviert für künftige Screen-Grafiken) |
| `_archive/` | Archivierte Quelldateien (nicht aktiv im Spiel; mit README) |
| `_dev/` | Inspirationsbilder und Referenzmaterial aus der Entwicklungsphase |
| `_wip/` | Work-in-progress-Dateien, die noch nicht finalisiert sind |

## Hinweise

- Aktive Spiel-Assets liegen als PNG direkt im jeweiligen Unterordner.
- Quelldateien (`.pxo`, `.ai`) bleiben neben den PNGs zur Nachvollziehbarkeit.
- Schriftart-Attributionspflicht: **Vecteezy.com** — siehe `fonts/` und Medienkatalog.
